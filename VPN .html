VPN Basics Flashcards Term Definition VPN Virtual Private Network - creates a secure, encrypted tunnel for internet traffic Encryption Converting data into a code to prevent unauthorized access Tunneling Process of encapsulating data packets inside another protocol VPN Protocol Set of rules defining how data moves through the tunnel (OpenVPN, WireGuard, etc.) Split Tunneling Routing only specific traffic through VPN while rest uses regular connection Kill Switch Feature that disconnects internet if VPN connection drops unexpectedly No-Log Policy VPN provider's promise not to store user activity records ✅ 2.
